# Official sources

Use these references for current details rather than copying stale rules into the skill:

- [Google Chrome Modern Web Guidance 101](https://codelabs.developers.google.com/codelabs/modern-web-guidance-101) — choose a Baseline target, establish Lighthouse measurements, prioritize one workstream, implement, and verify.
- [Modern Web Guidance repository](https://github.com/GoogleChrome/modern-web-guidance) — current agent-oriented web guidance and skill source.
- [Baseline](https://web.dev/baseline) — interoperable browser feature targets.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview) — automated audits for performance, accessibility, best practices, and SEO.
- [web.dev Learn](https://web.dev/learn) — current performance, accessibility, and responsive web learning paths.

Treat dates and browser support as time-sensitive. Record the chosen Baseline target in the project’s `AGENTS.md` or web documentation.
