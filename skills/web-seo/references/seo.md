# SEO checklist

For each public route, verify a unique title, useful meta description, canonical URL, one clear primary heading, rendered crawlable content, descriptive internal link text, correct language metadata, useful image alt text, and intentional index/follow behavior. Verify redirects, 404/410 responses, sitemap, robots rules, client-side routes, and social previews.

Structured data must describe visible content and follow the relevant Google Search feature documentation. It can make a page eligible for features; it does not guarantee ranking or appearance.
